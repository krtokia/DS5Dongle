Pico 2 W Wake — Wi-Fi 설정 주입기

빌드된 .uf2 안의 설정 블록에 SSID와 비밀번호를 써넣습니다.

이 페이지는 네트워크로 아무것도 보내지 않습니다.
파일 읽기·수정·저장이 전부 브라우저 안에서만 일어납니다. 인터넷 연결을 끊고 써도 됩니다.
GitHub Actions 아티팩트에서 받은 .uf2를 선택하세요.
최대 32바이트. 2.4GHz 대역이어야 합니다 (CYW43439는 5GHz 미지원).
8–63바이트.

다음 단계
  1. Pico 2 W의 BOOTSEL 버튼을 누른 채 USB를 연결합니다.
  2. RP2350 이름의 드라이브가 나타납니다.
  3. 방금 내려받은 *-configured.uf2를 그 드라이브에 끌어다 놓습니다.
  4. 보드가 자동으로 재부팅되며 Wi-Fi 접속을 시작합니다 (온보드 LED 깜빡임 → 상시 점등).
